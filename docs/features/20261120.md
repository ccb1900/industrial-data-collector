## 审查七项的裁决

1. **Go 与 UI 插件未成整体** — 属实（且更深：应用未接 `SetDeclarationSwitch`，
   控制台开关是 transient 直切 fiber，下次调和即被推翻）。已闭环：
   框架 follows 依赖门控（停用后端 = UI 行退 Pending；重启用自动恢复），
   应用接通声明开关（PatchReplace 翻转 Enabled，持久化进 patch 覆盖层），
   卸载/安装按 `<插件>:` 前缀级联。控制台仍逐行可见——**业务单元由依赖
   机制表达，不引入第二个生命周期管理器**（铁律 7）。
2. **flat 源采当天** — 属实，但**已是文档化例外**（`RECOVERY.md` 102-106、
   `CONFIGURATION.md` flat 段、3 条测试钉死）。裁决：维持现状不改代码；
   同日导出与补采窗口在语义上互斥，延迟到次日采集会丢失当天覆盖前的
   内容——这是有意的业务例外，不是缺省漏洞。
3. **30 天补采未成默认** — 属实。已改为产品默认：fleet 未声明
   `catchup_days` ⇒ 30（注入在 `sourcecomp.parseFleetDefaults` 单点，
   有效配置里可见）；显式 0 = 声明式 legacy 兼容口（保留
   `TestPlannerZeroCatchupKeepsLegacyWalk` 语义）；flat 强制 0。
4. **应用依赖滞后** — 属实（`44c1f27` → 本迭代 `d03fe96`）。已
   `bump-cordis.sh` 升级（含 `plugins/alarm-demo/go.mod`）；ui-page 工厂
   切到框架 `host.NewUIPageComponent`（renderer-or-views 由框架裁决），
   应用自维护的 `NewPage` 废除——内建与动态插件走同一条路。
5. **坏 manifest 静默消失** — 属实（且框架 discover.go 注释与实现自相
   矛盾）。已改为 `plugin-error` 行：损坏插件以 Failed + 可读原因留在
   组合与 explorer 中（Sync 返回带原因的错误）；修复 manifest = 修正
   声明 → replace 自动恢复。缺 manifest.toml 的目录仍按"不是插件"处理。
6. **BEGIN IMMEDIATE 注释与实现不符** — 属实。已补 `_txlock=immediate`
   （modernc 支持），DSN/注释一致；新增双 `*Store` 并发测试：先红（第一轮
   即 `SQLITE_BUSY (5)` 逃逸），后绿（败者确定性 `ErrRevisionConflict`，
   版本严格 +1）。
7. **并发闸 first-call-wins** — 属实（哪个源先构建决定全进程容量）。
   决策点移入 `sourcecomp.expandFleet`（fleet defaults 单点），组件构造
   不再 Configure；运行期改值响亮告警"change requires restart"——诚实
   重启语义，不造假热更。

## 对审查验收项的修正（有则改之，无则加勉）

- **"后端进程退出 → Hub 查询/命令同时撤销"**：未采纳字面含义。进程异常
  死亡不是生命周期事件（铁律 12 合作假设），且崩溃不重跑 Apply，无法用
  声明机制表达撤销；把瞬时故障变成整插件消失比可见错误更难诊断。现行
  语义：死亡 → `plugin.exited` 观察 + 查询诚实报 `plugin_error` + fiber
  保持 Active（降级不阻断），恢复走操作员开关。follows 跟踪的是**声明
  激活**，不是进程健康——启动失败/死亡时 UI 保留可见。
- **"后端启动失败应级联撤 UI"**：同理不采纳——降级可见优于消失可见。
- **explorer Pending 无原因诊断**：悬空 follows 的源头已由卸载级联消除
  （卸载根行连子行一起移除，Removed 列表只显示根行）；Snapshot 依赖诊断
  留框架后续，不在本迭代扩大面。

## 顺带修复（审查未点名但被验收测试暴露）

- `hReadyBound`：disabled 条目（Fiber==nil）原本会 nil 解引用 panic；
  合法依赖等待（Pending）原本被 Readiness 超时报失败。现以 2s 观察窗
  区分瞬时启动与合法等待，既不 panic 也不误放行。
- 框架 explorer：`Transient` 未透传到 DTO（前端无法标注"临时开关"）；
  声明分支在 switch 返回瞬间读状态，会报 Pending 而伪造"Accepted"
  （PE-11）。两处已在框架侧修复并 bump。
